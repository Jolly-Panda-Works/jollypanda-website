## Suggested Usage Mapping

| Location in project | Recommended address |
|---|---|
| `security.txt` / `.well-known/security.txt` | `security@jollypanda.ir` |
| Website contact form (future) | `contact@jollypanda.ir` |
| Footer "general inquiries" link | `info@jollypanda.ir` or `hello@jollypanda.ir` |
| Careers / Jobs page (roadmap) | `careers@jollypanda.ir` (or `jobs@jollypanda.ir`) |
| Press kit / media page | `press@jollypanda.ir` |
| Terms of Service / Privacy Policy | `legal@jollypanda.ir`, `privacy@jollypanda.ir` |
| Transactional/system emails | `noreply@jollypanda.ir` |

---

## Notes

- `jobs@` is a redundant alternative to `careers@` — pick one as primary and forward the other to avoid split inboxes.
- `accounts@` and `billing@` can usually forward to the same inbox unless a dedicated accounting workflow is set up.
- Consider setting up catch-all forwarding to `info@` or `hello@` for any address not explicitly listed above.
