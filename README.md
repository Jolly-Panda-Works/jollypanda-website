# Restaurant CFO
سامانه هوشمند تحلیل و مدیریت مالی رستوران

## ساختار پوشه‌ها

```
Restaurant-CFO/
├── site/
│   └── index.html                     صفحه فرود (jollypanda.ir/restaurant-cfo)
├── templates/
│   ├── Restaurant-CFO-Blank-EN.xlsx   نسخه انگلیسی، خام برای شروع کار مشتری
│   └── Restaurant-CFO-Blank-FA.xlsx   نسخه فارسی، خام برای شروع کار مشتری
├── demo/
│   ├── Restaurant-CFO-Demo-EN.xlsx    نسخه انگلیسی، با داده‌های نمونه پر شده
│   └── Restaurant-CFO-Demo-FA.xlsx    نسخه فارسی، با داده‌های نمونه پر شده
└── docs/
    └── راهنمای مدیر مالی رستوران.docx  راهنمای فارسی استفاده از فایل اکسل
```

## توضیح فایل‌ها

- **site/index.html** — همان صفحه فرودی که قرار است به‌عنوان ساب‌ماژول در ریپوی
  اصلی سایت (`jolly-panda-homepage`) در مسیر `restaurant-cfo/` قرار بگیرد؛
  طبق راهنمای راه‌اندازی که قبلاً نوشته شد، باید همین نام `index.html` را
  حفظ کند.
- **templates/** — چهار نسخه‌ی اکسل (فارسی/انگلیسی × نمونه‌پرشده/خام). نسخه‌های
  «Demo» برای نمایش و آموزش مشتری‌اند؛ نسخه‌های «Blank» همانی‌اند که برای
  استفاده‌ی واقعی به مشتری تحویل داده می‌شود.
- **docs/** — راهنمای Word (فارسی) که ساختار ۱۴ شیت فایل، راهنمای رنگ‌ها و
  روند کار را توضیح می‌دهد؛ همان چیزی که در صفحه فرود به‌عنوان «راهنمای Word
  همراه» به آن اشاره شده.

## نکته

فایل‌های نمونه (Demo) و خام (Blank) در هر دو زبان از نظر ساختار شیت‌ها
(۱۴ شیت یکسان) کاملاً مطابق‌اند؛ تنها تفاوت، پر یا خالی بودن سلول‌های
ورودی داده است.
